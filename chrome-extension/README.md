# FWLOG 查询结果插件

插件用于登录、填写简化查询条件并展示 `/api/query` 分页结果，同时在独立状态页显示日志接收情况、主机 CPU、内存、数据盘剩余空间和 ClickHouse 占用空间。没有下载、导出、任务管理或文件操作。

## 安装

1. 解压 `dist/fwlog-query-extension.zip`。
2. 打开 Chrome `chrome://extensions`，启用“开发者模式”。
3. 选择“加载已解压的扩展程序”，选择解压后的插件目录。
4. 点击扩展右上角设置按钮，确认服务地址为 `https://192.168.0.130:8080`。

测试机使用内网自签名证书时，先在 Chrome 打开 `https://192.168.0.130:8080/` 并完成证书信任，再使用扩展查询。

插件登录成功后只在当前扩展会话内保存 Bearer JWT，不保存管理员密码。

查询时间支持直接输入 `YYYY-MM-DD HH:mm`、`YYYY-MM-DD HH:mm:ss`、`YYYY/MM/DD HH:mm` 或紧凑数字格式。插件内日期面板通过 `/api/ingest-progress` 同步主程序的可查询、正在入库、等待处理和处理失败状态；同步失败时仍可手动输入时间查询。
