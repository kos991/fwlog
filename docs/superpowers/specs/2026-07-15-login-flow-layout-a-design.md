# 登录页柔性主链流程图设计

## 目标

只重做登录页左侧日志流程图，采用用户确认的 `A：柔性主链`。登录卡片、动态 Logo、背景网格、整体位置、节点文案和左下角状态条保持当前版本。本文件取代此前登录业务流设计中关于节点布局、线路结构和流程动效的约定，其他约定继续有效。

## 节点布局

保留现有五个节点及尺寸：

- 日志源：左下入口。
- RSyslog 接收：左上主节点。
- 数据存储：中部偏下。
- 日志查询：右上出口。
- 压缩归档：数据存储下方。

节点坐标保持为：

- 日志源：`translate(62 354)`。
- RSyslog 接收：`translate(354 222)`。
- 数据存储：`translate(718 344)`。
- 日志查询：`translate(1070 242)`。
- 压缩归档：`translate(718 470)`。

节点继续使用当前文案：`日志源 / 文件目录`、`RSyslog 接收 / UDP / TCP`、`数据存储 / ClickHouse`、`日志查询 / 快速检索`、`压缩归档 / 按策略保留`。

## 线路结构

蓝色主链只保留一条连续路径：

```text
日志源 -> RSyslog 接收 -> 数据存储 -> 日志查询
```

绿色归档支线只保留一条路径：

```text
RSyslog 接收 -> 压缩归档
```

线路要求：

- 每段线路从上游节点边缘出发，并在下游节点边缘结束。
- 主链采用连续贝塞尔缓弧，保留明显高低错落，不做水平直线排列。
- 删除数据存储上方悬空的灰色查询线路。
- 删除压缩归档右侧无目标节点的绿色延伸线。
- 不允许线路穿过节点文字或从节点另一侧继续伸出。
- 保留 `采集 / 入库 / 检索 / 归档` 四个路径标签。

路径使用以下确定坐标：

```text
主链：M204 410 C264 410 286 278 354 278 H520 C600 278 632 400 718 400 H884 C954 400 986 298 1070 298
归档：M437 334 C437 448 548 526 718 526
```

## 动效

- Anime.js 继续驱动节点图标呼吸和路径粒子。
- 蓝色粒子沿完整主链循环移动。
- 绿色粒子沿归档支线循环移动。
- 删除旧灰色查询支线对应的粒子和动画实例。
- 不新增悬停浮层、额外流光虚线或节点位移动画。
- 页面隐藏时暂停循环，减少动态效果模式继续使用现有静态降级。

## 保留内容

- 登录卡片结构、间距和交互不变。
- BrandLogo 及标题动画不变。
- 背景网格和场景透明度不变。
- 左下角 `INGEST PIPELINE` 状态条保持当前样式和文案。
- 移动端继续隐藏流程图，只显示登录卡片。

## 验证

- 前端测试断言只存在两条业务路径及两类路径粒子。
- 浏览器截图确认所有线路连接节点边缘，没有悬空、穿卡片或无目标延伸。
- 浏览器连续采样确认蓝绿粒子均在移动。
- 验证桌面端无重叠，移动端无横向溢出。
- 运行 `npm.cmd test`、`npm.cmd run build` 和 `git diff --check`。
