fwlog 离线防火墙 NAT 日志分析系统

面向内网运维场景 · 银河麒麟 V10 / Debian 服务器 · 纯离线部署

主要功能

日志自动入库

自动扫描深信服防火墙归档日志，解析 NAT 映射记录，批量写入内置 ClickHouse，支持增量导入和全量重建两种模式。

多维度日志查询

按时间、IP（源/目的/NAT）、端口、协议、动作、日志标签筛选，游标分页避免深翻页，自动只查已入库日期范围。

可视化仪表盘

入库进度、磁盘用量、今日/昨日行数、14 天日志趋势、IP 流量排行、GeoIP 国家地区分布、系统健康状态一览。

自动扫描计划

支持定点定时（daily）和固定间隔（interval）两种调度模式，自动触发增量入库，无需人工干预。

IP 归属标注

内置 GeoLite2 城市级地理库 + 自定义 CIDR 网段别名 + CSV 手工映射，查询结果和仪表盘自动标注 IP 归属。

系统运维管理

多日志源配置、CIDR 别名管理、GeoIP 开关、管理员密码修改、入库进度详情页（按日期/源展示文件级状态）。

在线升级

从 GitHub Release 拉取升级包，SHA256 完整性校验，校验包内不含 ClickHouse 文件，systemd-run 沙箱安装，自动备份配置和版本文件，安装后自动重启。

目的

  • 留存

    防火墙自身存储有限，日志滚动快，历史记录容易丢失。fwlog 将日志持久化到 ClickHouse，压缩存储，无时间限制，磁盘有多大存多久，满足等保合规对日志留存周期的要求。

  • 检索

    防火墙自带日志查看功能弱，无法跨日期、跨条件快速查询。fwlog 提供多维度筛选 + 秒级响应，运维人员能快速定位"某 IP 在某时间访问了什么"。

  • 溯源

    NAT 转换后真实 IP 与公网 IP 的映射关系是安全溯源的关键。fwlog 完整保留 NAT 映射记录，支持通过任意一端 IP（源/目的/NAT）反查完整链路，配合 GeoIP 标注快速判断访问来源。
