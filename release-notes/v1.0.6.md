# v1.0.6

## 本次修复

- 补齐旧版本在线升级兼容资产。
- GitHub Release 现在同时保留新资产名和旧兼容资产名：
  - `fwlog-upgrade-v{version}.x86_64.rpm`
  - `fwlog-upgrade_{version}_amd64.deb`
  - `nat-query-service_kylin-server_amd64.rpm`
  - `nat-query-service_debian-server_amd64.deb`

## 兼容说明

- `v1.0.4` 及更早版本继续按旧资产名识别升级包，因此现在可以从最新 Release 正常发现可升级版本。
- 新版本程序仍优先使用 `fwlog-upgrade` RPM/DEB 包执行在线升级。
- `nat-query-service_linux_amd64` 仍保留，用于旧版本先跳到新升级链路。
