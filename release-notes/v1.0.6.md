# v1.0.6

## 发布内容

- Release Build 不再被可选 Kylin 包阻塞，142 部署所需的 Linux amd64 产物独立生成。
- GitHub Actions 负责执行 Go 测试、前端构建和 Linux amd64 二进制生成。
- 142 服务器只部署 GitHub Release 产物，不在服务器源码目录执行测试或构建。

## 142 部署

在 `192.168.0.142` 上执行：

```bash
curl -fL https://github.com/kos991/fwlog/releases/download/v1.0.6/deploy-142-from-release.sh -o /tmp/deploy-142-from-release.sh
bash /tmp/deploy-142-from-release.sh v1.0.6
```
