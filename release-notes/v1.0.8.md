# v1.0.8

## 发布内容

- 统一前端主题令牌，按钮、输入框、表格、Tabs 使用同一套颜色、圆角和紧凑尺寸。
- 收敛登录页字号和间距，去掉大号输入框与按钮，让登录页和后台控制台风格一致。
- 统一卡片、表格、排行、进度和设置页的边线、白底容器和等宽数字显示。
- 修复侧栏折叠后标题文字残留的问题，折叠状态只显示图标。
- 未登录检查失败时不再弹出无意义的接口错误提示，直接进入登录页。

## 142 部署

在 `192.168.0.142` 上执行：

```bash
curl -fL https://github.com/kos991/fwlog/releases/download/v1.0.8/deploy-142-from-release.sh -o /tmp/deploy-142-from-release.sh
bash /tmp/deploy-142-from-release.sh v1.0.8
```
