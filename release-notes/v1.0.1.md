## 修复说明

- 修复银河麒麟 V10 SP1 服务器上 systemd 启动失败的问题。服务文件原来只允许写入 `/data/sangfor_fw_log` 和 `/data/index`，当 `/data/index` 尚未创建时，systemd 会在 namespace 阶段退出并显示 `status=226/NAMESPACE`。现在改为允许服务写入 `/data`，并在部署说明中明确创建 `/data/sangfor_fw_log`、`/data/index` 和 `/data/export`。
- 修复 Web 页面打开“自动增量同步”并保存时报 `Cannot POST /api/settings` 的问题。前端保存设置使用 `POST /api/settings`，后端现在已注册该路由，并继续保留兼容路由 `POST /api/settings/log-dir`。
