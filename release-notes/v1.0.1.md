# v1.0.1

补丁版本，保持 v1 架构不变。该版本只修复当前生产使用中发现的问题，并补齐安装包内容。

## 修复的问题

- 日志查询带筛选条件时只能查询 7 天，无法满足按 IP 回查一个月内日志的需求。现在无筛选查询仍限制为 1 天；填写 IP、端口、协议、结果或日志名称后，最多支持 31 天。
- 查询范围超限提示不够清楚。现在页面和后端错误都会分别说明“无筛选最多 1 天”和“带筛选最多 31 天”。
- RPM / DEB 安装包没有包含 GeoIP 数据库。现在打包时默认从 `P3TERX/GeoLite.mmdb` 最新 Release 拉取 `GeoLite2-City.mmdb`，并安装到 `/data/index/GeoLite2-City.mmdb`。
- 系统设置页的版本升级卡片文案和视觉层级与维护页其它卡片不一致。现在统一为中文状态、中文说明和相同的信息密度。

## 内部整理

- 拆分 `internal/app/app.go` 的路由、导入、设置、查询、看板和安全适配器代码，便于后续维护；不改变 HTTP API 和数据模型。

## 验证

- `npm.cmd run build`
- 已在 `192.168.0.142` 验证服务启动、首页、`/api/session` 和带 IP 的 31 天查询。
