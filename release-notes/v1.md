# v1

新的生产基线版本。

## 主要内容

- 采用 `cmd/nat-query-service` 与 `internal/app` 的 Go 项目布局。
- Release 资产从旧版本重新收敛为三个文件：
  - `nat-query-service_linux_amd64`
  - `nat-query-service_kylin-server_amd64.rpm`
  - `nat-query-service_debian-server_amd64.deb`
- RPM / DEB 安装包内置私有 ClickHouse 运行时。
- 系统设置页继续通过纯二进制执行在线升级。
