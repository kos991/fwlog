# v1.1.1

## 发布内容

- 重做系统设置页 Release 升级卡片逻辑，参考“软件更新”面板模型展示当前版本、检查更新、自动检查更新和升级状态。
- 新增“自动检查更新”设置，只在进入设置页时检查 GitHub Releases，不会自动下载或安装。
- 发现新版本且 Release 资产齐全时才展示“升级到 vX.Y.Z”按钮；资产缺失、检查失败和升级失败会固定显示在卡片内。
- 前端新增升级状态展示逻辑测试，并接入 `npm test`。

## 发布资产

本版本只发布 Linux amd64 产物：

- `nat-query-service_linux_amd64`
- `nat-query-service.service`
- `deploy-142-from-release.sh`

## 142 部署

在 `192.168.0.142` 的系统设置页执行 Release 升级：

1. 点击“检查更新”，确认可升级版本为 `v1.1.1`。
2. 点击“升级到 v1.1.1”。
3. 服务自动重启后再次检查，确认当前版本为 `v1.1.1`。
