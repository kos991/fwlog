# v1.0.5

## 本次发布

- 合并此前两次补丁内容，一次性发布到正式版本。
- 修复管理员密码修改后重启失效的问题，并将密码规则调整为至少 6 位、不限制字符类型。
- 修复数据概览顶部系统状态条在窄宽度下被压缩的问题，状态信息保持完整可读。
- RPM/DEB 升级前自动备份并在升级后恢复 `app_settings`，避免扫描计划、日志源、IP 库路径、升级开关和管理员密码等运行配置被默认值覆盖。

## 升级能力

- 新版本程序在线升级时，优先下载并安装 `fwlog-upgrade` RPM/DEB 包，不再直接替换运行中的二进制。
- Release 继续保留 `nat-query-service_linux_amd64`，保证旧版本仍可先升级到新链路。
- 同时产出 `fwlog-full` 全量包和 `fwlog-upgrade` 升级包。
- `fwlog-upgrade` 包会在安装前校验内容，不允许携带 ClickHouse runtime 或 `fwlog-clickhouse.service`。

## 运行维护

- 新增自动扫描调度器，按配置时间自动触发入库，并记录最近一次自动扫描时间。

## 验证结果

- 已通过 `go test ./...`
- 已通过 `npm.cmd run build`
- 已通过 `bash -n packaging/build-server-packages.sh`
