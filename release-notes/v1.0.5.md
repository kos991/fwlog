# v1.0.5

## 发布内容

- 修复 systemd 服务文件缺少 `LOG_TAG=深信服 NAT` 导致的 CI 失败。
- GitHub Actions 负责执行 Go 测试、前端构建和 Linux amd64 二进制生成。
- 142 服务器只部署 GitHub Release 产物，不在服务器源码目录执行测试或构建。
- Release 资产包含 `nat-query-service_linux_amd64`、`nat-query-service.service` 和 `deploy-142-from-release.sh`。

## 142 部署

在 `192.168.0.142` 上执行：

```bash
curl -fL https://github.com/kos991/fwlog/releases/download/v1.0.5/deploy-142-from-release.sh -o /tmp/deploy-142-from-release.sh
bash /tmp/deploy-142-from-release.sh v1.0.5
```

部署脚本会安装到 `/opt/nat-query/nat-query-service`，刷新 systemd，并重启 `nat-query-service`。
