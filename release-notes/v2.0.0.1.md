# FWLog v2.0.0.1 测试版

这是 V2 主线的测试发布版本，用于验证当前 V2 打包、升级和部署链路。

## 重点

- 以当前 `main` 分支作为 V2 测试主线。
- full 包用于首次离线安装，包含私有 ClickHouse runtime。
- upgrade 包用于应用升级，不携带 ClickHouse runtime。
- `/opt/fwlog/RUNTIME_VERSION` 只由 full 包交付，upgrade 包不改写 runtime 元数据。

## 安装包

- `fwlog-full-v2.0.0.1-amd64.tar.gz`：首次离线安装包。
- `fwlog-upgrade-v2.0.0.1.x86_64.rpm`：RPM 升级包。
- `fwlog-upgrade_2.0.0.1_amd64.deb`：DEB 升级包。
- `fwlog_kylin-server_amd64.rpm`：兼容旧命名的 RPM 升级包。
- `fwlog_debian-server_amd64.deb`：兼容旧命名的 DEB 升级包。
