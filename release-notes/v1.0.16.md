# v1.0.16

## 本次修复

- 修复 `v1.0.15` 在线升级校验失败的问题：升级包下载到临时文件后，现在按 GitHub Release 资产原名匹配 `checksums.txt`，并兼容 checksum 文件里的绝对路径。
- 修复 Kylin/RPM 从旧 `nat-query-service` 包升级到 `fwlog-upgrade` 时的文件冲突问题，RPM 包增加旧包替换声明。
- 修复 Debian/Ubuntu 包升级兼容性，DEB control 增加 `Provides/Replaces/Breaks: nat-query-service`。
- 修复 Release `checksums.txt` 生成范围，只在最终 Release 资产复制完成后重新生成，并覆盖二进制、兼容包名、full 包和 upgrade 包。

## 验证范围

- `go test ./...`
- `npm.cmd test`
- `npm.cmd run build`

## 备注

- 本机未运行 `go test -race`：Windows 环境缺少 `gcc`，`runtime/cgo` 无法构建；Release workflow 会在 Ubuntu runner 上执行 race 测试。
