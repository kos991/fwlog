# fwlog v2.0.0.4 测试版

这是 V2 主线的第四个测试版本，修复测试版在线检查更新时误报 Release 资产缺失的问题。

## 本次更新

- 测试构建和四段版本号改为从 GitHub prerelease 通道检查更新，不再错误读取旧稳定版。
- 更新判断改为数字版本比较，避免把旧版本误判为新版本并触发降级提示。
- 支持 `vX.Y.Z.N-test.<commit>` 测试构建升级到同号 `vX.Y.Z.N` Release。
- 在线升级入口支持三段稳定版和四段测试版版本号。
- 补充发布通道选择、版本顺序、资产完整性和维护页版本格式回归测试。

## 说明

- 本版本属于升级阻断修复，建议正在测试 V2 主线的环境更新。
- 四段版本号会在 GitHub Release 中标记为 prerelease。
