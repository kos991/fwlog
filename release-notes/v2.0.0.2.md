# fwlog v2.0.0.2 测试版

这是 V2 主线的第二个测试版本，重点修复数据概览和维护页体验，并加入第一版 RSyslog UDP 接收能力。

## 本次更新

- 日志趋势改为按日期展示，并支持按设备筛选。
- 日志趋势支持“全部设备”聚合视图，空数据时只显示 0 基线。
- 维护页改为纵向结构：扫描计划、入库操作、版本升级。
- 维护页文案统一为简体中文，去掉旧英文文案和“自动升级”表述。
- 修复前端 mock 和默认日志源中的中文乱码。
- 新增 RSyslog 日志源配置模型：
  - 默认协议：UDP
  - 默认监听端口：5514
  - 默认落盘目录：`/data/fwlog/received/<source_id>`
- 新增应用内 UDP RSyslog 接收器，收到日志后按日期写入 spool 文件，后续入库继续复用现有导入链路。
- 新增 RSyslog 接收状态接口：`/api/receiver/status`。

## 说明

- 当前版本只实现 UDP 接收，TCP 接收暂未开放。
- RSyslog 接收器不会直接写入 ClickHouse，只负责落盘。
- 如端口被占用，主服务仍会启动，并在接收状态中显示错误。
