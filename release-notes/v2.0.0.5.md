# fwlog v2.0.0.5 测试版

这是 V2 主线的第五个测试版本，修复入库完成后仍长期显示 `100% / 入库中` 的状态问题，并统一后台用户可见文案。

## 本次更新

- 新建状态表使用微秒级更新时间；现有状态表通过终态时间保护和确定性排序，避免同一秒内的“正在入库”和“已完成”记录发生竞争。
- 启动时自动修复文件已处理完成但仍停留在“正在入库”的历史日期状态。
- 入库进度达到 100% 但尚未确认终态时显示“收尾中”，完成后明确显示文件数和入库行数。
- 统一概览、入库进度、日志查询和系统维护页面中的状态、日志来源及操作名称。
- 重新导入操作明确提示会清除所选来源、所选日期已有的入库结果后再处理。
- RSyslog 配置支持发送端地址留空，并明确接收目录、压缩目录和保留天数的含义。
- 在线升级、本地升级包、发布文件和运行组件版本采用统一中文说明。
- 页面直接展示的入库 API 错误改为可执行的中文提示，保留原 HTTP 状态码和机器错误码。

## 说明

- 本版本不会修改现有 ReplacingMergeTree 版本列类型，启动时会自动执行兼容旧表的状态修复，无需手工变更数据库。
- 本版本为四段版本号测试版，GitHub Release 将标记为 prerelease。
