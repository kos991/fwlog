# fwlog v2.0.0.6 测试版

这是 V2 主线的第六个测试版本，紧急修复 `v2.0.0.5` 在 ClickHouse 25.8 上查询入库状态时的别名展开冲突。

## 本次更新

- 状态聚合排序使用表限定列名，避免 `status` 别名被展开为嵌套聚合表达式。
- 保留 `v2.0.0.5` 的入库终态修复、后台文案整理和中文错误提示。
- 补充状态版本列限定测试，并在 ClickHouse 25.8.27 实际状态表上验证查询结果。

## 说明

- 已安装 `v2.0.0.5` 的测试环境应立即升级到本版本。
- 本版本为四段版本号测试版，GitHub Release 将标记为 prerelease。
