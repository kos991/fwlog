# v1.0.9

## 发布内容

- 统一控制台视觉风格，收敛登录页、数据概览、查询页、入库进度和系统设置的主色、边框、背景和字号。
- 调整登录页和概览页 SVG 动效配色，保留轻量动效，避免和后台页面视觉冲突。
- 默认收起侧栏，并在页面切换后保持收起状态；管理员入口和退出按钮在收起状态下保持可用。
- 统一日志源、CIDR 别名、维护操作等设置区域的表格化编辑风格。
- 保持日志量、排行数值、耗时、进度等数字使用等宽字体，提升列表对齐效果。

## 142 部署

在 `192.168.0.142` 上执行：

```bash
curl -fL https://github.com/kos991/fwlog/releases/download/v1.0.9/deploy-142-from-release.sh -o /tmp/deploy-142-from-release.sh
bash /tmp/deploy-142-from-release.sh v1.0.9
```
