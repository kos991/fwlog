# fwlog v1.0.0

这是 fwlog V2 主线的首个正式版本，版本号从 `v1.0.0` 开始。

## 核心能力

- 接收并解析 Huawei USG、H3C、Fortinet FortiGate 等防火墙 NAT 日志。
- 支持文件日志与 Syslog 接收，提供接收进度、日志来源和扫描计划管理。
- 支持日志重建、网段别称和数据处理状态管理。
- 提供按时间、IP、端口、协议、动作和日志来源检索 NAT 五元组的查询页面。
- 提供访问趋势与主机状态概览，支持国内、国外访问趋势查看。
- 提供查询 API、MCP 接口以及 Chrome 插件下载入口。

## 安全与运维

- 支持首次启动初始化管理员账号。
- 支持密码登录与 MFA 登录方式切换。
- 使用 JWT 会话认证，并支持密码可见性切换。
- 提供 API 和 MCP 接口开关及下载配置。
- 提供主机 CPU、内存、磁盘剩余空间、数据库大小和日志接收状态查看。
- 支持 HTTPS、自签名证书配置和 systemd 服务运行。

## 数据与性能

- 概览统计使用按日预聚合，常态查询避免扫描长期原始日志。
- 访问趋势使用预聚合和缓存，降低大数据量下的查询延迟。
- 冷排行与历史回填采用单 worker，降低对查询服务的资源影响。
- 日志重建支持按日期处理，并同步维护原始日志及相关聚合数据。

## 支持的交付物

- `fwlog_linux_amd64`：Linux amd64 主程序。
- `fwlog-full-v1.0.0-amd64.tar.gz`：离线完整安装包。
- `fwlog-full-v1.0.0.x86_64.rpm`、`fwlog-full_1.0.0_amd64.deb`：完整安装包。
- `fwlog-upgrade-v1.0.0.x86_64.rpm`、`fwlog-upgrade_1.0.0_amd64.deb`：应用升级包。
- `checksums.txt`、`latest.json`：文件摘要和升级清单。

## 发布与升级说明

- 正式发布使用 GitHub tag `v1.0.0`。
- 完整安装包包含 ClickHouse 运行时；升级包不包含 ClickHouse 运行时。
- 升级前应确认数据盘有足够空间，并保留应用配置和 ClickHouse 数据备份。
- 升级流程会校验 `checksums.txt`，校验失败时拒绝安装升级包。
