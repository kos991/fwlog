# v1.1.0

## 发布内容

- 日志查询新增游标分页，`/api/query` 返回 `next_cursor` 和 `has_more`，前端翻页不再主动制造深 `OFFSET` 查询。
- 查询结果使用稳定排序：`timestamp DESC, source_id DESC, source_file DESC, source_offset DESC`，同一秒多条日志也能稳定翻页。
- 增加查询保护：无筛选查询最多 24 小时，带筛选查询最多 7 天，旧分页超过第 20 页会提示改用游标。
- 增加服务端查询超时和并发保护，超时、过宽查询、并发过高分别返回 `query_timeout`、`query_too_broad`、`query_busy`。
- 修复看板地区排行空白场景，地区数据可由目的 IP 标注聚合补齐，同时前端增加空状态展示。
- 保留后续 ClickHouse 优化路线：物化视图预聚合、`dst_ip` / `nat_ip` skip index、异步导出、Dictionary / Projection / 冷热分层均需先验证再上线。

## 发布资产

本版本只发布 Linux amd64 产物：

- `nat-query-service_linux_amd64`
- `nat-query-service.service`
- `deploy-142-from-release.sh`

## 142 部署

在 `192.168.0.142` 上执行：

```bash
curl -fL https://github.com/kos991/fwlog/releases/download/v1.1.0/deploy-142-from-release.sh -o /tmp/deploy-142-from-release.sh
bash /tmp/deploy-142-from-release.sh v1.1.0
```
