# v1.0.2

## 修复

- 修复入库进度接口默认时间窗口过窄的问题，历史日期正在导入时不再误显示为空闲。
- 修复系统设置页扫描时间保存后回到 `01:00` 的问题。
- 入库接近完成时显示为“收尾中”，避免最后一个文件处理期间长期显示 `99%`。
- 优化自动扫描关闭状态的文案，明确计划时间只在启用后生效。
- 新安装默认关闭自动扫描，避免 RPM/DEB 首次安装后立即导入历史日志。
- 服务启动时对 ClickHouse 连接增加有限重试，避免安装阶段 ClickHouse 尚未就绪导致服务直接失败。

## 改进

- 数据概览页新增 CPU、内存、ClickHouse 状态。
- `/api/health-dashboard` 新增 `system_health` 字段。
- 新增系统支持列表：`SYSTEM_SUPPORT.md`。

- `nat-query-service_linux_amd64`
- `nat-query-service_kylin-server_amd64.rpm`
- `nat-query-service_debian-server_amd64.deb`
