# fwlog v2.1.0 正式版

这是 V2 主线首个正式发布版本，汇总此前测试版本的入库稳定性修复，并完成 IPv6 扩展、登录与后台界面统一、日志接收可靠性和必要安全加固。

## 本次更新

- 日志解析、查询、CIDR 别名、地址展示和 ClickHouse 存储链路支持 IPv6，IPv4 与 IPv6 使用统一的地址处理规则。
- 重构登录页品牌标识和日志处理流程动效，统一登录卡片、后台导航及系统维护页面的布局与中文文案。
- 修复历史日期手动入库、重建后状态仍停留在 `100% / 入库中`、状态聚合别名冲突等问题。
- 修复空归档或零有效日志被错误标记为“已完成”的问题；现在会显示“无有效日志”，并自动纠正旧的零行终态记录。非空但无法识别的日志会明确标记为处理失败，避免静默产生假完成状态。
- 完善日志来源管理和 TCP/UDP 日志接收状态；TCP 接收增加来源预检、连接上限、空闲超时和配置重载同步。
- gzip 日志导入增加解压总量限制和任务取消检查，避免异常归档长期占用资源。
- 登录失败改为按来源限流，并限制登录请求体、密码长度和并发密码校验，避免跨来源锁定和资源放大。
- 移除固定默认管理员密码；RPM/DEB 首次安装会生成独立随机密码文件 `/etc/fwlog/admin-password`，权限仅限 root。
- 在线升级缺少 `checksums.txt` 时拒绝安装；未签名的手动上传升级默认关闭；发布部署脚本在替换程序前校验 SHA256。
- 修复大数据量 IPv4 到 IPv6 表迁移超过 30 秒后连接超时、残留临时表导致服务无法启动的问题；迁移现在支持长查询并可在切表前安全重试。

## 升级说明

- 支持从现有 V2 测试版本直接升级，已保存的管理员密码和应用设置继续保留。
- 首次安装后可执行 `sudo cat /etc/fwlog/admin-password` 查看初始管理员密码，登录后应立即修改。
- 手动上传 RPM/DEB 升级包默认禁用，日常升级请使用带完整校验文件的正式 Release；仅在受控维护窗口中可临时设置 `ALLOW_UNSIGNED_UPGRADE_UPLOAD=true`。
- 本版本包含 IPv6 表结构迁移。升级前应保留 ClickHouse 数据备份，旧版程序不支持迁移后的双栈表结构，不建议直接回滚二进制。

## 发布文件

- `fwlog_linux_amd64`：Linux amd64 主程序。
- `fwlog-full-v2.1.0-amd64.tar.gz`：首次离线安装包。
- `fwlog-full-v2.1.0.x86_64.rpm`、`fwlog-full_2.1.0_amd64.deb`：完整安装包。
- `fwlog-upgrade-v2.1.0.x86_64.rpm`、`fwlog-upgrade_2.1.0_amd64.deb`：应用升级包。
- `checksums.txt`、`latest.json`：文件摘要和升级清单。
