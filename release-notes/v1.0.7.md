# v1.0.7

## 发布内容

- 统一数据概览、日志查询、入库进度、系统设置和登录页的界面风格。
- 查询页默认只展示日期和 IP，更多筛选条件默认收起；日期面板内标注可查和未入库范围。
- 系统设置新增多设备日志目录维护，并在 IP 库内集中管理 CIDR 网段别名，支持添加、删除和启用开关。
- 自动扫描、手动入库和指定日期重建统一放入维护页。
- 列表和排行中的日志量、占比、时间、IP、端口等数字统一使用等宽数字显示。
- 删除不能真实还原的地图展示，避免假地图误导。

## 142 部署

在 `192.168.0.142` 上执行：

```bash
curl -fL https://github.com/kos991/fwlog/releases/download/v1.0.7/deploy-142-from-release.sh -o /tmp/deploy-142-from-release.sh
bash /tmp/deploy-142-from-release.sh v1.0.7
```
