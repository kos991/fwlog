# v1.1.2

## 发布内容

- 继承 `v1.1.1` 的 Release 升级页重做：当前版本展示、检查更新、自动检查更新、卡片内状态与错误提示。
- 修复应用内自动升级替换二进制失败的问题：下载完成后先写同目录临时文件，再原子替换目标二进制，避免 `text file busy`。
- 修复 systemd 沙箱配置：允许服务写入 `/opt/nat-query`，用于备份和替换自身二进制。
- 修复 Release 部署脚本：安装新二进制前先停止 `nat-query-service`，再安装并重启。

## 发布资产

本版本只发布 Linux amd64 产物：

- `nat-query-service_linux_amd64`
- `nat-query-service.service`
- `deploy-142-from-release.sh`

## 142 部署

`v1.1.1` 的页面逻辑已可检查 Release，但旧进程自身升级会被 systemd 写权限和运行中文件替换问题阻塞。首次修复建议在 142 上执行本版本 Release 部署脚本完成引导升级；升级到 `v1.1.2` 后，后续版本可继续使用页面内 Release 升级。
