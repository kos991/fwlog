# fwlog v2.0.0.3 测试版

这是 V2 主线的第三个测试版本，重点重做管理员登录页的视觉层级、数据流动效和响应式体验。

## 本次更新

- 登录页改为全屏浅色数据拓扑场景，左侧展示日志源、RSyslog 接收、数据存储、压缩归档和日志查询链路。
- 使用 Anime.js 统一管理场景入场、链路粒子、节点图标和登录反馈动画。
- 将 Logo、产品名和管理员登录身份集成到登录卡片，移除重复标题和独立品牌区。
- 修复 SVG 节点和粒子坐标叠加导致的错位、裁切和脱离路径问题。
- 登录成功后播放短暂退场动画，登录失败后提供局部反馈并重新聚焦密码输入框。
- 移动端隐藏背景拓扑，只保留完整登录卡；支持 `prefers-reduced-motion` 静态降级。
- 补充登录页结构、动画选择器、响应式布局和 SVG 坐标回归测试。

## 说明

- 本版本不修改登录接口、Session、Cookie 或管理员密码校验逻辑。
- 桌面数据流仅作状态语义展示，不读取或展示真实生产设备、地址和日志数量。
- 当前版本为测试版，四段版本号会在 GitHub Release 中标记为 prerelease。
