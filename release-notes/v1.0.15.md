# v1.0.15

## 安全修复

- 修复大量 API 端点无认证的问题：query、dashboard、settings、sync、rebuild、ip-data-reload 等全部端点现在要求登录，未鉴权请求返回 401。
- 修复 `/api/settings` POST 可注入 `admin_password_hash` 接管管理员的问题：settings 现在拒绝 `admin_password_hash` 键，密码修改只能走 `/api/password`。
- 修复 `looksLikePasswordHash` 不校验迭代次数下限的问题：现在要求 iterations ≥ 10000。
- 登录接口增加速率限制：5 次失败后 5 分钟冷却。
- 启动时若使用默认密码 admin，输出 stderr 告警。
- Session cookie 增加 `Secure` 标志（通过 `COOKIE_SECURE` 环境变量控制）和 `MaxAge=86400`（24 小时过期）。
- Session token 比较改用 `subtle.ConstantTimeCompare` 防止时序攻击。
- Logout 接口现在要求登录态。
- 错误响应不再暴露 `err.Error()` 内部细节（含 ClickHouse 连接串、文件路径等），改为统一友好消息。
- ClickHouse `users.xml` 移除 `access_management=1`，防止本机进程无口令管理用户。

## 稳定性修复

- 后台 goroutine（导入/升级）增加 panic 恢复，panic 不再崩溃进程，状态自动复位为 failed。
- HTTP server 增加 ReadTimeout/WriteTimeout/IdleTimeout，main.go 增加信号处理和优雅关闭。
- 后台导入增加 2 小时超时 context，防止 ClickHouse 连接 hang 导致导入槽位永久占用。
- 升级 HTTP 请求改用专用 client（10 分钟超时）替代 `http.DefaultClient`。
- 升级包下载增加 512MB 大小限制，防止超大文件耗尽磁盘。
- 升级包下载后增加 SHA256 校验（从 Release `checksums.txt` 读取）。
- 升级流程执行前备份 `nat-query-service.service` 和 `VERSION` 到 `/data/nat-query/backups/`。
- 下载文件权限从 0o755 改为 0o644。
- 日志扫描跳过符号链接，防止符号链接穿越攻击。
- ClickHouse 连接增加服务端 `max_execution_time=15`、`max_rows_to_read=1亿`、`ReadTimeout=30s`。
- Dashboard 请求增加 20 秒超时 context。
- `bufio.Scanner` 单行上限从 1MB 增到 10MB，减少超长行导致整日导入失败。
- ClickHouse `nat-query-service.service` 从 `Wants` 改为 `Requires` fwlog-clickhouse，CH 启动失败时 app 不再被拉起。
- `fwlog-clickhouse.service` 增加 `StartLimitInterval`/`StartLimitBurst` 防止无限重启循环。
- RPM/DEB 安装脚本 `app_settings` 备份失败时中止升级（`exit 1`），不再静默吞错。
- RPM/DEB 安装脚本 ClickHouse 启动失败时中止安装，不再 `|| true` 继续拉起 app。

## 功能修复

- `interval` 自动扫描模式从死代码改为真正生效：`BuildAutoScanPlan` 和 `dueAutoScanTime` 按 `auto_scan_mode` 分发 daily/interval。
- 移除 `2.0.0.0/8` 硬编码"政务网私有段"，改为通过 `CIDRAliases` 配置，不再吞掉公网 GeoIP 结果。
- 查询可见性"未入库日"不再触发 `Partial=true`，区分"无状态"与"未就绪"。
- `protocol IN (?, ?, ?)` 改为 `IN (?, ?)`，删除 `"<数字>,"` 死逻辑绑定值。
- 打包脚本生成 `checksums.txt`，Release 上传时纳入 allowed_assets。

## 前端修复

- API 层识别 401 响应，自动触发 `onUnauthorized` 回调回到登录页，不再"假死"。
- API 请求增加 30 秒超时（AbortController），防止慢后端请求堆积。
- 维护页 save 不再硬编码 `auto_scan_mode='daily'`/`auto_scan_interval_sec='86400'`，改为读 form 值。
- 日志查询 `runSearch` 增加 catch，翻页失败显示错误提示而非静默。
- 升级轮询网络错误时显示"服务重启中"提示；升级成功后展示"点击刷新"引导。

## CI 修复

- CI 和 Release workflow 增加 `npm test` 运行前端测试。
- Go 测试改为 `go test -race -count=1`，启用竞争检测。
- 修复 `deploy-142-from-release.sh` 下载不存在的 Release 资产导致必定失败的问题，改为内联 systemd unit 文件。
- 测试注释中 `npm.cmd`（Windows-only）修正为 `npm`。

- `npm test`
- `npm run build`
