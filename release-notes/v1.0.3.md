## 更新说明

- 支持深信服防火墙 NAT 日志目录中的更多真实文件形态：`*.log`、`*.log-YYYYMMDD` 和 `*.log-YYYYMMDD.gz`。压缩日志使用流式 gzip 解压读取，不需要先手动解压。
- 保留当前深信服 NAT 中文字段解析，继续识别 `源IP`、`源端口`、`目的IP`、`目的端口`、`协议`、`转换后的IP` 和 `转换后的端口`。
- 新增自定义“日志标志”，默认值为 `深信服 NAT`。设置页可修改，页面顶部、查询结果和导出 CSV 都会显示该标志。
- 对 gzip 归档文件按归档文件处理；如果压缩文件大小变化，会触发全量重建，避免压缩流偏移和明文偏移混用导致索引不一致。
